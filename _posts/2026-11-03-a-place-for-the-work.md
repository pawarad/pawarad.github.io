Most of what I build never leaves a cluster. A pipeline that cuts BAMs from 88 GB to 38 GB, a fix that makes copy number models behave on low tumor fraction cell-free DNA, an agent that curates solutions in minutes: each one lives in a lab directory and a few chat threads.

This site is where I will start writing those down. The plan is simple:

- Short posts, one idea each, with the code or the result that backs it up.
- Notes on GPU bioinformatics, copy number and ctDNA methods, and the agentic tools we are building around them.
- Honest accounts, including what did not work.

If one of these is useful to you, or wrong, I would like to hear about it.
